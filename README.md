# یادآور قرص نیایش

ربات تلگرام که هر روز، سر ساعتی که خودتان تنظیم می‌کنید، به نیایش یادآوری می‌کند دارو را بخورد. لحن ربات گرم است و بعد از هر یادآوری یک جملهٔ مهربان می‌گوید.

سرور همیشه‌روشن ندارد. گیت‌هاب هر ۵ دقیقه یک بار برنامه را روشن می‌کند، کارش که تمام شد خاموش می‌شود. حافظهٔ دائمی یک فایل به نام `data.json` داخل همین ریپو است، نه دیسک یک سرور.

## قبل از هر کار: توکن

توکن ربات مثل رمز عبور است.

- توکن را فقط در Secret گیت‌هاب با اسم دقیق `BOT_TOKEN` بگذارید.
- توکن را داخل کد، `README`، چت، اسکرین‌شات، یا `data.json` نگذارید.
- اگر توکن یک بار در چت، ایمیل، یا جایی عمومی دیده شده، در تلگرام به [@BotFather](https://t.me/BotFather) دستور `/revoke` بدهید و توکن تازه بگیرید. توکن قبلی را دور بریزید.
- این ریپو را Public می‌سازیم چون دقیقهٔ رایگان گیت‌هاب اکشنز برای ریپوی عمومی تمام نمی‌شود. به همین خاطر **اسم دقیق دارو هم عمومی می‌شود**، چون داخل `data.json` ذخیره و دوباره به ریپو فرستاده می‌شود. در دستور `/add` اسم کوتاه بگذارید، مثل «قرص صبح» یا «ویتامین شب»، نه نام کامل نسخه.

## این ربات چه کار می‌کند

هر اجرا این ترتیب را طی می‌کند:

1. `data.json` را می‌خواند. اگر خراب باشد همان اجرا را متوقف می‌کند.
2. پیام‌ها و دکمه‌های جدید تلگرام را با `getUpdates` می‌گیرد.
3. اگر ساعت یک یادآور، به وقت تهران، رسیده باشد و هنوز امروز فرستاده نشده باشد، پیام می‌فرستد.
4. اگر چیزی عوض شده باشد، خودِ workflow همان `data.json` را commit و push می‌کند.

فاصلهٔ اجراها دقیق نیست. برای همین ارسال اول فقط از ساعت مقرر تا ۳۰ دقیقه بعدش قبول است، و هر یادآور در هر روز فقط یک بار ارسال اول دارد. اگر تا ۱۵ دقیقه دکمهٔ «خوردم» زده نشود، حداکثر دو بار دیگر یادآوری می‌آید. دیرکرد خیلی طولانی (بیشتر از ۳۰ دقیقه بعد از موعد یادآوری مجدد) فرستاده نمی‌شود تا نصفه‌شب ناگهان زنگ نزند.

هر `chat_id` فقط یادآورهای خودش را می‌بیند. یادآورها به همان تلگرامی می‌رود که دستور را فرستاده است. نیایش باید از گوشی خودش به ربات پیام بدهد.

## زنگ روی آیفون

ربات نمی‌تواند داخل برنامهٔ ساعت آیفون آلارم بسازد. اپل این اجازه را به ربات تلگرام نمی‌دهد. چیزی که واقعاً به گوشی می‌رسد، اعلان تلگرام است. اگر این تنظیمات روشن باشد، همان اعلان صدا می‌دهد:

1. کلید فیزیکی سایلنت کنار آیفون را از حالت نارنجی خارج کنید. در حالت سایلنت، آیفون معمولاً فقط می‌لرزد.
2. در آیفون بروید به **تنظیمات ← اعلان‌ها ← تلگرام**.
3. «اجازه دادن به اعلان‌ها»، «صداها»، «قفل صفحه» و «بنرها» را روشن کنید.
4. «اعلان‌های حساس به زمان» (Time-Sensitive Notifications) را روشن کنید تا در حالت تمرکز هم برسد.
5. در **تنظیمات ← تمرکز**، تلگرام را برای حالت مزاحم نشوید مجاز کنید.
6. داخل تلگرام: **تنظیمات ← اعلان‌ها و صداها ← گفتگوهای خصوصی** و یک صدای مشخص انتخاب کنید.
7. از گوشی نیایش `/test` بفرستید و workflow را یک بار دستی اجرا کنید. اگر صدا آمد، مسیر درست است.

برای قرص‌های خیلی مهم، علاوه بر ربات، یک آلارم روزانه هم در برنامهٔ ساعت آیفون بگذارید. ربات دکمهٔ «خوردم» و تعویق ۱۰ دقیقه‌ای را دارد؛ ساعت گوشی فقط زنگ بلند سیستم را دارد.

جواب ربات فوری نیست. بعد از هر پیام باید صبر کنید تا اجرای بعدی گیت‌هاب برسد. معمولاً چند دقیقه است و گاهی گیت‌هاب دیرتر بیدار می‌شود.

## دستورها

از گوشی نیایش، در گفتگوی خصوصی ربات:

| دستور | کار |
| --- | --- |
| `/start` | خوش‌آمد، راهنما، و معنی نمادها |
| `/add 08:00 قرص صبح` | یادآور هر روز، سر همین ساعت |
| `/add ۰۸:۳۰ ویتامین` | همان دستور با عدد فارسی |
| `/list` | فهرست یادآورهای همین گوشی، با شماره |
| `/del 1` | حذف شمارهٔ ۱ از فهرست خودش |
| `/history` | دفعاتی که در ۷ روز اخیر «خوردم» زده شده |
| `/test` | یک زنگ آزمایشی برای امتحان صدای آیفون |

موقع یادآوری دو دکمه می‌آید:

- **خوردم ✅** — پیام به «✅ آفرین، ثبت شد» عوض می‌شود و در تاریخچه می‌ماند.
- **۱۰ دقیقه بعد ⏰** — حدود ۱۰ دقیقهٔ دیگر یک بار دیگر می‌گوید.

نماد موقع `/add` از روی کلمهٔ اسم انتخاب می‌شود. مثلاً اگر در اسم «فشار» باشد نماد ❤️ است و ربات همان‌جا معنی نماد را می‌گوید. این نمادها اسم دارو نیستند و چیزی دربارهٔ نسخه فاش نمی‌کنند.

## فایل‌ها

- `bot.py` — منطق ربات، فقط با کتابخانهٔ `requests`
- `requirements.txt` — فقط `requests`
- `.github/workflows/bot.yml` — زمان‌بندی هر ۵ دقیقه و اجرای دستی
- `data.json` — یادآورها، تاریخچه، و شمارهٔ آخرین آپدیت تلگرام
- `.gitignore` — فایل رمز و محیط مجازی را بیرون نگه می‌دارد

## دیپلوی، قدم‌به‌قدم

این کارها را خودتان انجام می‌دهید. ساخت حساب گیت‌هاب به ایمیل و تأیید خودتان نیاز دارد و از این کامپیوتر، بدون ورود شما، ممکن نیست.

### ۱. ربات تلگرام

1. در تلگرام [@BotFather](https://t.me/BotFather) را باز کنید.
2. `/newbot` را بفرستید.
3. یک اسم نمایشی و یک یوزرنیم که به `bot` ختم شود انتخاب کنید.
4. توکن را کپی کنید و فقط پیش خودتان نگه دارید. این‌جا پیست نکنید.

اگر این ربات را قبلاً ساخته‌اید و توکنش جایی دیده شده، `/revoke` و بعد توکن تازه.

### ۲. حساب گیت‌هاب

1. به [github.com/join](https://github.com/join) بروید.
2. با ایمیل خودتان حساب بسازید و ایمیل را تأیید کنید.
3. اگر برنامهٔ `gh` را می‌خواهید، در PowerShell یک بار `gh auth login` را اجرا کنید و وارد همان حساب شوید.

### ۳. ریپوی خالی و Public

1. در گیت‌هاب **New repository** را بزنید.
2. اسم دلخواه، مثلاً `pill-reminder`.
3. **Public** را انتخاب کنید. ریپوی خصوصی دقیقهٔ رایگان اکشنز را زود تمام می‌کند: این ربات روزی حدود ۲۸۸ بار بیدار می‌شود.
4. تیک README و gitignore را نزنید تا با فایل‌های همین پوشه قاطی نشود.
5. ریپو را بسازید.

### ۴. فرستادن فایل‌ها

در PowerShell، داخل همین پوشه:

```powershell
cd C:\Users\yasin\Desktop\trading
git init
git branch -M main
git add bot.py requirements.txt README.md .gitignore data.json .github
git commit -m "Add the pill reminder bot"
git remote add origin https://github.com/USERNAME/pill-reminder.git
git push -u origin main
```

`USERNAME` را با نام حساب خودتان عوض کنید. اگر `git` اسم شما را نپرسیده بود و commit خطا داد، اسم و ایمیل گیت را طبق راهنمای گیت‌هاب برای خودتان تنظیم کنید. توکن را در این دستورها ننویسید.

با `gh` هم می‌شود، بعد از `gh auth login`:

```powershell
gh repo create pill-reminder --public --source=. --remote=origin --push
```

### ۵. Secret توکن

**راه گرافیکی**

1. ریپو را باز کنید.
2. **Settings ← Secrets and variables ← Actions**.
3. **New repository secret**.
4. اسم را دقیقاً بنویسید: `BOT_TOKEN`
5. مقدار را همان توکن تازهٔ BotFather بگذارید و Save کنید.

**راه ترمینال** (توکن را نشان نمی‌دهد؛ وقتی پرسید بچسبانید):

```powershell
gh secret set BOT_TOKEN
```

اسم Secret باید همین باشد. کد جای دیگری توکن نمی‌خواند.

### ۶. روشن کردن Actions

1. تب **Actions** ریپو را باز کنید.
2. اگر گیت‌هاب پرسید، تأیید کنید که workflowها اجازهٔ اجرا دارند.
3. سمت چپ **Pill reminder** را انتخاب کنید.
4. **Run workflow** و بعد دوباره **Run workflow**. این همان `workflow_dispatch` است.
5. اجرای سبز یعنی توکن قبول شده و ربات یک دور بیدار شده است.
6. اگر قرمز شد، لاگ را باز کنید. خطای توکن یعنی Secret خالی یا باطل است. لاگ نباید خودِ توکن را نشان بدهد.

زمان‌بندی `*/5 * * * *` فقط روی برنچ پیش‌فرض (معمولاً `main`) اجرا می‌شود. اگر ۶۰ روز هیچ اجرایی نیاید، گیت‌هاب زمان‌بندی را خاموش می‌کند و باید از همان تب Actions دوباره روشنش کنید.

### ۷. تست با گوشی نیایش

1. از تلگرامِ گوشی نیایش، ربات را باز کنید و `/start` بفرستید.
2. workflow را دستی اجرا کنید، یا تا ۵ دقیقه صبر کنید.
3. `/test` بفرستید و دوباره workflow را اجرا کنید. آیفون باید صدا بدهد.
4. یک یادآور آزمایشی با اسم کوتاه بسازید: `/add` و ساعتی که در ۳۰ دقیقهٔ گذشته یا چند دقیقهٔ آینده است.
5. `/list` و `/history` را هم یک بار بزنید.
6. روی پیام یادآوری، «خوردم ✅» و یک بار «۱۰ دقیقه بعد ⏰» را امتحان کنید. عوض شدن متن پیام تا اجرای بعدی طول می‌کشد.

## دیسک دائمی

دیسکی برای وصل کردن وجود ندارد، چون سروری در کار نیست.

حافظهٔ دائمی همین `data.json` است:

- یادآورها
- `last_update_id` تا پیام تکراری پردازش نشود
- `sent_log` تا هر دارو در هر روز فقط یک بار ارسال اول شود
- `intake_log` برای `/history`

آخرِ workflow، اگر این فایل عوض شده باشد، با اجازهٔ `contents: write` به برنچ فعلی commit و push می‌شود. اجرای بعدی همان فایل را از گیت می‌خواند. همزمانی هم با `concurrency` بسته شده تا دو اجرا با هم روی فایل ننویسند.

چیزی به نام Volume یا دیسک ابری لازم نیست. اگر برنچ را Protect کرده باشید و به `github-actions[bot]` اجازهٔ push ندهید، ذخیره‌سازی شکست می‌خورد. برای این ربات شخصی، محافظتی که push ربات را ببندد نگذارید.

`data.json` را در `.gitignore` نگذارید. اگر بگذارید، بعد از هر اجرا حافظه پاک می‌شود.

چون ریپو عمومی است، این فایل را همه می‌توانند ببینند. داخلش توکن نیست، ولی اسمی که با `/add` وارد شود و شناسهٔ عددی چت تلگرام هست. اسم داروها را کوتاه و غیرمشخص انتخاب کنید.

## اگر کار نکرد

- **ربات جواب نمی‌دهد:** اجرای workflow باید بعد از پیام شما آمده باشد. بدون اجرای اکشنز کسی به تلگرام وصل نیست.
- **یادآور نیامد:** ساعت به وقت تهران است. اگر بیشتر از ۳۰ دقیقه از ساعت مقرر گذشته باشد، همان نوبت عمداً ارسال نمی‌شود و فردا سر ساعت دوباره امتحان می‌شود.
- **صدا نمی‌آید:** بخش آیفون بالا را چک کنید، به‌خصوص کلید سایلنت و اعلان حساس به زمان. `/test` را از همان گوشی بفرستید.
- **یادآور به گوشی شما آمده نه گوشی نیایش:** دستور `/add` از همان حسابی ذخیره می‌شود که پیام را فرستاده. نیایش باید از تلگرام خودش اضافه کند.
- **Secret را عوض کردید ولی هنوز خطا می‌دهد:** یک بار **Run workflow** را دستی بزنید. توکن قدیمی را در BotFather باطل کنید.
